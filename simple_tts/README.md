# 基础 TTS 语音合成

简单、快速的文本转语音服务，支持在线和本地双模式，即开即用，无需 GPU。

## 功能特性

- **在线模式（edge-tts）** — 微软 Azure 在线语音，5 种中文自然音色，音质好，速度快
- **本地模式（pyttsx3）** — 本地系统语音，完全离线，无需网络连接
- **即时合成** — 无需加载模型，毫秒级响应
- **语速调节** — 支持 0.5x ~ 2.0x 语速调整
- **语音选择** — 在线 5 种 / 本地 2 种语音自由切换

## 系统要求

| 组件 | 要求 |
|------|------|
| **Python** | 3.8+ |
| **网络** | 在线模式需要联网，本地模式不需要 |
| **GPU** | 不需要 |
| **依赖** | Flask, edge-tts, pyttsx3 |

## 安装指南

### 1. 创建虚拟环境（推荐）

```bash
python -m venv venv

# Windows 激活
venv\Scripts\activate

# Linux/Mac 激活
source venv/bin/activate
```

### 2. 安装依赖

```bash
pip install flask edge-tts pyttsx3 requests psutil
```

> `pyttsx3` 在 Windows 上使用系统自带的 SAPI5 语音引擎，无需额外安装。
> Linux 上需要安装 espeak：`sudo apt install espeak`

## 启动服务

```bash
cd simple_tts
python app.py
```

启动后显示：

```
============================================================
🎙️ 基础 TTS 语音合成服务
============================================================
在线语音数：5
本地语音数：2
服务地址：http://localhost:5001
============================================================
```

## 使用方法

### 1. 访问页面

打开浏览器访问：**http://localhost:5001**

### 2. 选择模式

- **在线模式** — 使用微软 edge-tts，需要联网，音质好，速度快（推荐）
- **本地模式** — 使用 pyttsx3，完全离线，无需网络

### 3. 选择语音

根据模式自动切换可选语音列表：

**在线语音：**
| 语音 | 说明 |
|------|------|
| 晓晓 (女声) | 标准女声，推荐 |
| 云希 (男声) | 标准男声 |
| 云健 (男声-沉稳) | 沉稳男声 |
| 晓伊 (女声) | 活泼女声 |
| 云扬 (男声) | 磁性男声 |

**本地语音：** 取决于操作系统安装的语音包。

### 4. 输入文本并生成

- 输入任意文本，点击"生成语音"按钮
- 文字较少时响应更迅速
- 建议单次不超过 1000 字符

### 5. 播放音频

- 生成完成后自动播放
- 可下载或重新播放

## API 接口

### 提交合成任务

```bash
curl -X POST http://localhost:5001/api/speak \
  -H "Content-Type: application/json" \
  -d '{
    "text": "你好，欢迎使用语音合成服务",
    "speed": 1.0,
    "voice": "zh-CN-XiaoxiaoNeural",
    "mode": "online"
  }'
```

参数说明：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | string | 是 | 要合成的文本 |
| `speed` | float | 否 | 语速（0.5~2.0，默认 1.0） |
| `voice` | string | 是 | 语音 ID |
| `mode` | string | 是 | 模式：`online` 或 `local` |

返回示例：

```json
{"success": true, "task_id": "xxx-xxx-xxx"}
```

### 查询任务状态

```bash
curl http://localhost:5001/api/status/xxx-xxx-xxx
```

### 获取音频文件

```bash
curl http://localhost:5001/audio/xxx.mp3 --output output.mp3
```

## 故障排除

### 在线模式失败

```
失败：连接超时
```

**原因：** 网络连接问题或 edge-tts 服务不可用
**解决：**
1. 检查网络连接
2. 切换到本地模式
3. 确认能访问微软 Azure 服务

### 本地模式无声音

```
失败：No voice found
```

**原因：** 系统未安装语音包
**解决：**
- **Windows**：控制面板 → 语音识别 → 文本到语音转换 → 添加语音
- **Linux**：`sudo apt install espeak`

### 端口被占用

```
Address already in use
```

**解决：**
1. 关闭占用端口的程序
2. 或修改 `app.py` 中的 `port=5001` 为其他端口
